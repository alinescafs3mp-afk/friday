## G7 (#54). Нерусский текст утекает пользователю на экран

Спецификация V2, §9.3: любой видимый пользователю нерусский текст — баг. Найдено при
сверке (раздел «Абсолютные ограничения» в корневом `TASKS.md`).

Путь целиком: `admin_api/_knowledge.py:245` отдаёт `detail="Knowledge object not found"`,
`admin_ui/static/app.js:20` делает `throw new Error(data?.detail)`, и `app.js:535`
показывает это через `toast(e.message, true)`. То есть английская строка из кода API
доезжает до экрана дословно.

Это не одна строка: пройди `detail=` по `admin_api/` и `api/` и посмотри, какие из них
достижимы этим путём. Английские сообщения в ЛОГАХ — по спецификации правильно, их не
трогай; речь только о том, что видит человек.

Сторожевой тест напрашивается инвентарный: собрать `detail=` со всех маршрутов и
потребовать русского у тех, что доходят до `toast`. Помни правило проекта — инвентарный
тест, пропускающий часть поверхности, прячет дефект ровно в ней; если какой-то маршрут
проверить нельзя, пусть он **сообщает о себе**, а не молча пропускается.
