# live-grant.v1

Encoding: canonical ASCII JSON, sort_keys=True, compact separators, allow_nan=False and one LF. Duplicate/unknown/missing keys and noncanonical round trips fail. External expected SHA256 is mandatory for authority documents; local/staged/self manifests never supply trust. Lowercase 64-hex digests, exact bools versus ints, bounded paths/counts/depth/sizes. Every nested record is exact-key checked by the named source parser. Source constants define the closed executable field inventory; source-review-index binds their symbols and tests.

Parser: broker_runtime.parse_live_grant. Grant binds authority ID/digest, exact one attempt/candidate/generation, snapshot/rootfs/golden, fixed argv/environment, capacity/topology, timeouts/output limit/evidence allowlist/startup receipt and one_terminal_attempt=true. Its expected digest is separately supplied by root-approved trust. Exact argv begins protected venv Python -I -S -B and real candidate-relative tools/quality_gate.py. Environment is rebuilt from the fixed empty-base allowlist; any loader/startup/plugin/package/proxy/browser injection refuses. Provenance/index/install grant alone cannot admit live execution. Permanent consumption precedes snapshot verification, custody, admission or lock.

Both grant and authority expected hashes are mandatory strict external SHA256 values at direct parser entry; null/boolean/numeric pins never downgrade to structural parsing. The startup_receipt is a declaration checked against protected inventory, not a host receipt proving already executing interpreter/bootstrap bytes or their protected startup lifetime. Production bootstrap refuses before package loading until an independently accepted startup/anchor mechanism is supplied. No callback or local receipt can upgrade fixture authority.
