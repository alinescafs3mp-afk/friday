# snapshot-manifest.v1

Encoding: canonical ASCII JSON, sort_keys=True, compact separators, allow_nan=False and one LF. Duplicate/unknown/missing keys and noncanonical round trips fail. External expected SHA256 is mandatory for authority documents; local/staged/self manifests never supply trust. Lowercase 64-hex digests, exact bools versus ints, bounded paths/counts/depth/sizes. Every nested record is exact-key checked by the named source parser. Source constants define the closed executable field inventory; source-review-index binds their symbols and tests.

Parser: manifest.parse_snapshot_manifest and verify_snapshot. Exact top-level keys: schema,contract,snapshot_id,creation_tool_sha256,created_utc,candidate,platform,materials_sha256,runtime_contract_sha256,members,root_merkle_sha256. Candidate binds commit/tree/root_identity/controller_path/quality_gate_sha256/preflight_sha256/broker_package_sha256. Platform binds machine/ABI/CPython ABI/import suffixes/rootfs image/kernel/loader contracts. Member common keys path,type,uid,gid,mode,nlink,mount_domain; file adds size,sha256,executable_class; symlink adds target,target_sha256. Complete sorted inventory, root identity/device/mount and metadata are compared through retained descriptors. Writability/ACL/capabilities/specials/link escape/loops/extra or missing members fail. verify_snapshot returns HeldSnapshot owning a descriptor; custody must use and revalidate it, never reopen an ordinary execution path.

Parsing authenticates structure and bytes; production compatibility requires independently pinned material requirements through validate_snapshot_requirements. Every declared controller/preflight/broker/runtime/kernel/loader digest must match its required manifested file; platform ABI/import/rootfs declarations and owner-approved rootfs/golden canonical domain inventories must match the external requirement. The minimum complete toolchain/native dependency contract and host lease remain NOT_PROVEN; structural parsing alone cannot grant installation/live authority.

Copied-root InstallationBinding is reconstructed only from a protected immutable journal and the exact externally pinned grant/identity. purpose=staged permits installer verification phases; purpose=installed requires installed_not_live. The install journal's closed authorized effect/object graph is reconstructed from journal_plan_from_grant and parsed before issuing the typed binding. Complete manifest/provenance envelope files are additional exact root:root 0444 nlink1 same-mount subjects outside the manifested payload inventory, with mandatory external byte digests whenever present; a half envelope is refused.

PinnedRoot.parent_lease retains each subordinate ancestor descriptor and validates named/opened/post full identities and mounts before/after effects. Returned descriptors retain parent ancestry until the owning root closes. Bare _parent descriptors are refused. The source proves sampled identity custody with safe retained-file and model controls; it does not claim atomic hostile-UID/kernel enforcement between syscalls.
