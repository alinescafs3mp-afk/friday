# material-provenance.v1

Encoding: canonical ASCII JSON, sort_keys=True, compact separators, allow_nan=False and one LF. Duplicate/unknown/missing keys and noncanonical round trips fail. External expected SHA256 is mandatory for authority documents; local/staged/self manifests never supply trust. Lowercase 64-hex digests, exact bools versus ints, bounded paths/counts/depth/sizes. Every nested record is exact-key checked by the named source parser. Source constants define the closed executable field inventory; source-review-index binds their symbols and tests.

Parser: provenance.parse_material_provenance and verify_owner_approved_materials. Exact top-level keys: schema,manifest_sha256,assembly_recipe_sha256,creation_tool_sha256,approved_authorities,artifacts,owner_approval. Each artifact binds class, canonical filename, format/tag/ABI, size, digest, approved external authority, signed index/signature, signer/key and verifier digest. Owner approval binds ordered artifact/signer set and manifest/candidate/generation/rootfs/golden identities. The accepted authority/key set and approval digest are external capability inputs. Artifact bytes must exactly match; missing verifier, unknown algorithm or local-cache self-approval refuses. The materials projection excludes later manifest binding to avoid a digest cycle.

Verifier binding: bind_fixed_verifier_source accepts externally pinned source bytes, compiles them without execution, and compares the fixed verify/_authority/_text code with the actual loaded implementation, including the fixed RSA digest prefix. The approved authority verifier digest must equal this implementation digest. A freely supplied approving callback is refused for production. fixture_authority must be the exact boolean true for synthetic callbacks; every result is issued and permanently labelled fixture. require_approved_materials refuses unissued/reconstructed/modified objects and fixture results at production consumers.

Closed requirements document schema=friday.material-requirements.v1 has exact REQUIREMENT_KEYS/REQUIREMENT_PLATFORM_KEYS/SUBJECT_KEYS from provenance. Its externally pinned artifact identities include class/name/format/tag/ABI/size/digest. The complete ordered REQUIRED_SUBJECT_ROLES is mandatory. Correct signatures and fresh external pins do not waive incompatible identities. Manifest subject/ABI/rootfs/golden comparisons use manifest.validate_snapshot_requirements. These source controls do not prove the complete A009 toolchain/publisher/native closure. Production material capability issuance unconditionally refuses FORMAT_NOT_COVERED until authentic requirements and reviewed raw receipt conversion are supplied; no synthetic artifact or fixture requirement creates production authority.
