# consumed-attempt.v1

Encoding: canonical ASCII JSON, sort_keys=True, compact separators, allow_nan=False and one LF. Duplicate/unknown/missing keys and noncanonical round trips fail. External expected SHA256 is mandatory for authority documents; local/staged/self manifests never supply trust. Lowercase 64-hex digests, exact bools versus ints, bounded paths/counts/depth/sizes. Every nested record is exact-key checked by the named source parser. Source constants define the closed executable field inventory; source-review-index binds their symbols and tests.

Parser: ledger.record_for/consume_once/ConsumedAttempt.validate. Exact keys: schema,attempt_id,candidate_commit,candidate_tree,attempt_generation,authority_sha256,live_grant_sha256,package_index_sha256,snapshot_manifest_sha256,broker_bundle_sha256. schema=consumed-attempt.v1. attempt_id is candidate_commit-generation, independent of snapshot replacement. Filename is always consumed.v1 under separately pinned candidate/generation parent. Exclusive no-follow create, complete write, file fsync, parent fsync and stable reopen are required before any live boundary. Every pre-existing type/byte state blocks permanently. No reset/delete/repair/retry/reuse API. Reinstall/uninstall/new snapshot cannot reinterpret the old key.

Consumed identity remains held through the supervisor's terminal commit/read-only acceptance and finalization. A final result binds this record hash with runtime/evidence/commit hashes; interruption or late cancellation supplies failure/veto only. Child/pipe ownership is registered before post-fork callbacks, and pidfd failure can signal only the exact direct unreaped child; bounded WNOHANG abort preserves an unreaped owner as STOP_UNCONFIRMED rather than pretending cleanup succeeded.
