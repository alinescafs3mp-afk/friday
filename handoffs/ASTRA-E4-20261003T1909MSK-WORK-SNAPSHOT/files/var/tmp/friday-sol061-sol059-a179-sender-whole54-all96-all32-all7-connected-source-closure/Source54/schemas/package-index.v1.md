# package-index.v1

Encoding: canonical ASCII JSON, sort_keys=True, compact separators, allow_nan=False and one LF. Duplicate/unknown/missing keys and noncanonical round trips fail. External expected SHA256 is mandatory for authority documents; local/staged/self manifests never supply trust. Lowercase 64-hex digests, exact bools versus ints, bounded paths/counts/depth/sizes. Every nested record is exact-key checked by the named source parser. Source constants define the closed executable field inventory; source-review-index binds their symbols and tests.

Parser: authenticated bootstrap/InstallPlan. Exact keys: schema,members. schema=friday.package-index.v1. Each sorted unique regular member: path,role,mode,size,sha256; relative path beneath package, integer mode0600 for this private source package, size bound, SHA256 of final bytes. Roles source/schema/template/effect/test/fixture/document. The index excludes itself and terminal result/test/review/manifest evidence. Terminal manifest closes those separately. A future installed bootstrap bundle is a separate grant-bound package index; private source digest does not authorise its installation.

Authority callers use mandatory digest APIs such as canonical.parse_authenticated_object and PinnedRoot.read_authenticated. Null/absent/wrong-type pins never downgrade authentication to structural parsing. The structural parse_canonical_object/read_exact APIs intentionally remain available for bounded non-authority data, with optional digests explicitly distinguished. Every production index/trust/grant caller must enforce mandatory external SHA256 and exact integer mode/descriptor types before loading package code.
